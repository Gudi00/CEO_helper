# Быстрый старт: подсказки в тестах

От нуля до первой подсказки — четыре шага. Подробности и другие способы установки — в [INSTALL.md](INSTALL.md).

## Шаг 1. Установка (один раз)

Скачайте репозиторий и запустите установку из его папки.

| ОС | Что сделать |
|---|---|
| **Windows** | Двойной щелчок по `scripts\install.bat` |
| **macOS** | Двойной щелчок по `scripts/install.command` (если macOS не даёт открыть — правый щелчок → «Открыть») |
| **Linux** | В терминале: `sh scripts/install.sh` |

Скрипт ставит сервер `lms-tool`, создаёт файл настроек и собирает расширение.
Для сборки расширения нужен [Node.js](https://nodejs.org) 20 или новее — если его нет, скрипт скажет об этом; поставьте Node.js и запустите установку ещё раз.

## Шаг 2. Откуда брать ответы

Выберите один вариант.

**А. Ручной режим — без ключей и без сервера.** Ничего настраивать не нужно, переходите к шагу 3. Шаг «Запуск сервера» тоже можно пропустить.

**Б. Нейросеть через сервер.** Откройте файл настроек — его путь печатает `lms-tool doctor` — и заполните один из блоков:

| Источник | Что вписать |
|---|---|
| Google Gemini | `GEMINI_API_KEY=` — ключ с <https://aistudio.google.com/apikey> |
| OpenRouter, DeepSeek, Groq, LM Studio | `OPENAI_BASE_URL=`, `OPENAI_API_KEY=`, `OPENAI_MODEL=` |
| Локальная модель | `OLLAMA_ENABLED=true`, затем `ollama pull <модель>` |

Проверьте: `lms-tool doctor` — напротив выбранного источника должно стоять `[OK]`.

## Шаг 3. Расширение в Chrome (один раз)

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (справа вверху).
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/dist`.
4. Закрепите значок «СЭО helper» на панели, чтобы он был под рукой.

Если ваш сайт с тестами — не `lms.bsuir.by`: значок расширения → «Настройки» → «Адрес вашего Moodle» → «Подключить».

## Шаг 4. Каждый раз перед тестом

### С нейросетью

1. **Запустите сервер.**

   | ОС | Как |
   |---|---|
   | Windows | Двойной щелчок по `scripts\start.bat` |
   | macOS | Двойной щелчок по `scripts/start.command` |
   | Linux | `sh scripts/start.sh` |

   Окно сервера закрывать нельзя, пока идёт тест. Чтобы не запускать его вручную, один раз выполните `lms-tool autostart on` — сервер будет стартовать сам при входе в систему.

2. **Свяжите расширение с сервером** (только в первый раз). В окне сервера есть строка «Код сопряжения: 123456». Нажмите значок расширения и введите эти 6 цифр. Код действует 2 минуты; новый выдаёт `lms-tool pair`.

3. **Нажмите значок расширения → «Начать».** Статус сменится на «Подсказки включены».

4. **Откройте страницу теста.** Под каждым вопросом появится плашка: сначала «В очереди…», потом «Нейросеть думает…», затем ответ — номер варианта, уверенность, модель и краткое объяснение. Вариант подсвечивается зелёным; оранжевый цвет означает, что модель сомневается.

5. После теста нажмите «Остановить».

### В ручном режиме

1. Значок расширения → «Источник ответа» → «Вручную, без сервера».
2. Откройте страницу теста. Под каждым вопросом — кнопка «Скопировать вопрос» и поле ввода.
3. Нажмите «Скопировать вопрос», вставьте его в любую нейросеть (ChatGPT, Gemini, DeepSeek…).
4. Скопируйте её ответ в поле и нажмите «Показать ответ» — нужный вариант подсветится. Достаточно последней строки вида «Ответ: 2».

## Режимы и модели

| Настройка | Что делает |
|---|---|
| Режим «Подсказки» | Только показывает ответ, отмечаете вы сами |
| Режим «По шагам» | Предлагает ответ и отмечает его после вашего подтверждения (Enter — применить, Esc — отменить) |
| Модель «Быстрая» | Первая настроенная модель из цепочки Gemini → OpenAI-совместимый API → Ollama |
| Модель «Точная» | Более сильная модель, если она настроена (`OPENAI_MODEL_ACCURATE` или Ollama) |

Названия моделей в списке приходят с сервера — видно, что именно будет отвечать.

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| «Сервер не отвечает» | Запустите сервер (шаг 4); проверьте `lms-tool doctor` |
| «Свяжите расширение с сервером» | Введите код сопряжения; новый — `lms-tool pair` |
| «На сервере не настроена ни одна нейросеть» | Заполните файл настроек (шаг 2) или включите ручной режим |
| На вопросе ошибка | Кнопка «Повторить» или «Ответить вручную» прямо под вопросом |
| «Этот тип вопроса пока не поддерживается» | Поддерживаются вопросы с выбором одного или нескольких вариантов |
| На странице теста ничего не появилось | Обновите страницу; проверьте, что нажато «Начать» и что адрес сайта подключён (шаг 3) |
| Команда `lms-tool` не найдена | Откройте новое окно терминала |

## Полезные команды

| Команда | Зачем |
|---|---|
| `lms-tool run` | Запустить сервер |
| `lms-tool doctor` | Проверить, что настроено и что нет |
| `lms-tool pair` | Новый код сопряжения |
| `lms-tool init` | Создать файл настроек |
| `lms-tool autostart on` / `off` / `status` | Автозапуск сервера при входе в систему |
| `lms-tool bench файл.jsonl` | Сравнить модели на своих вопросах |
