# Установка СЭО helper

Короткий путь от установки до первой подсказки — в [QUICKSTART.md](QUICKSTART.md). Здесь — подробности.

Продукт состоит из двух частей: **сервер** (`lms-tool`) на вашем компьютере и **расширение** для Chrome.
Для ручного режима сервер не нужен — достаточно расширения.

## 1. Сервер

Нужна копия репозитория. Установочный скрипт сам поставит `uv` и подходящий Python.

| ОС | Установка | Запуск сервера потом |
|---|---|---|
| Windows | двойной щелчок по `scripts\install.bat` | `scripts\start.bat` |
| macOS | двойной щелчок по `scripts/install.command` | `scripts/start.command` |
| Linux | `sh scripts/install.sh` | `sh scripts/start.sh` |

Скрипт установки ставит сервер, создаёт файл настроек (`lms-tool init`) и собирает расширение, если есть Node.js.

Автозапуск сервера при входе в систему: `lms-tool autostart on` (выключить — `off`). Его же включает
установка с ключом: `sh scripts/install.sh --autostart` или `install.bat -Autostart`.
Используется штатный механизм ОС: служба пользователя systemd, LaunchAgent или папка «Автозагрузка».
База ответов и настройки лежат в каталоге настроек пользователя, поэтому сервер работает одинаково
из любой папки.

Если Python 3.12 уже есть, можно без скрипта: `pip install ./backend` (или `pipx install ./backend`).

### Готовая программа без Python

К релизам на GitHub приложены архивы `lms-tool-linux.tar.gz`, `lms-tool-macos.tar.gz`
и `lms-tool-windows.zip`. Распакуйте и запускайте `lms-tool` из папки — устанавливать ничего не нужно.
Сверьте файл с `SHA256SUMS` из того же релиза.

Программы не подписаны, поэтому Windows (SmartScreen) и macOS (Gatekeeper) покажут
предупреждение при первом запуске. Если это мешает — используйте установку скриптом выше.

Собрать такую программу самому: `pip install "./backend[bundle]"`, затем `python backend/packaging/build.py`.

Проверка и запуск:

```
lms-tool doctor    # что работает, что нет и что сделать
lms-tool run       # запустить сервер
```

### Источник ответов

Настройки лежат в файле `.env` в каталоге настроек — его путь печатает `lms-tool doctor`.
Образец со всеми параметрами: [`backend/.env.example`](../backend/.env.example).
Достаточно любого одного источника:

| Источник | Что указать в `.env` |
|---|---|
| Google Gemini | `GEMINI_API_KEY` |
| Любой OpenAI-совместимый API (OpenRouter, DeepSeek, Groq, LM Studio, llama.cpp) | `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL` |
| Локальная модель через Ollama | `OLLAMA_ENABLED=true`, затем `ollama pull <модель>` |

Если настроено несколько, сервер идёт по цепочке Gemini → OpenAI-совместимый → Ollama
и переходит к следующему при ошибке или лимите.

Сравнить модели на своих вопросах:

```
lms-tool bench backend/bench/questions.example.jsonl
```

Формат файла — одна строка на вопрос с известным верным ответом (см. пример).
Трёх вопросов из примера для выводов мало: соберите хотя бы несколько десятков по своим дисциплинам.

### Docker

```
docker compose up -d --build
docker compose logs backend | grep "Код сопряжения"
```

Порт публикуется только на `127.0.0.1`.

## 2. Расширение

```
cd extension
npm install
npm run build
```

В Chrome: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `extension/dist`.

### Свой сайт Moodle

По умолчанию расширение работает на `lms.bsuir.by`. Для другого сайта откройте
«Настройки → Адрес вашего Moodle», введите адрес и нажмите «Подключить» —
Chrome спросит разрешение на доступ к этому сайту.

## 3. Сопряжение

1. Запустите `lms-tool run`. В окне появится строка «Код сопряжения: 123456».
2. Откройте окно расширения и введите эти 6 цифр.

Код действует 2 минуты и срабатывает один раз. Новый код: `lms-tool pair`.

После сопряжения сервер отвечает только этому расширению.

## Формулы и картинки

Формулы попадают в вопрос исходным текстом (TeX). Картинки из вопроса отправляются
нейросети вместе с текстом — до 4 штук, PNG/JPEG/WebP, до 1 МБ каждая.
Чтобы от них был толк, модель должна уметь работать с изображениями
(например, Gemini или vision-модель в Ollama). Ответы на вопросы с картинками не кешируются.

## Ручной режим

В окне расширения выберите «Источник ответа → Вручную, без сервера».
Под каждым вопросом появятся кнопка «Скопировать вопрос» и поле для ответа:
вставьте вопрос в любую нейросеть, а её ответ — обратно в поле.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Сервер не отвечает» | Запустите `lms-tool run`; проверьте `lms-tool doctor` |
| «Расширение не связано с сервером» | Введите код сопряжения (`lms-tool pair`) |
| «Сервер связан с другим расширением» | Расширение переустановили — введите новый код (`lms-tool pair`) |
| «На сервере не настроена ни одна нейросеть» | Заполните `.env` или включите ручной режим |
| «Нейросеть недоступна или исчерпан лимит» | «Повторить» позже или «Ответить вручную» на вопросе |
| «Этот тип вопроса пока не поддерживается» | Поддерживаются вопросы с выбором одного или нескольких вариантов |
| Команда `lms-tool` не найдена | Откройте новый терминал или выполните `uv tool update-shell` |
