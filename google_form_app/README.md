# Google Forms AI (`google_form_app`)

Автономное мобильное приложение (Flutter, iOS + Android), которое помогает
проходить тесты в **Google Forms** с помощью Gemini. Работает **локально на
устройстве, без серверного бэкенда**: ключ Gemini и все вызовы AI живут на
телефоне.

Это независимый продукт; исходный проект (Chrome-расширение + Python-бэкенд для
Moodle) в репозитории остаётся как донор кода.

## Что умеет

- Открывает Google-форму во **встроенном WebView** и парсит вопросы прямо из
  живой страницы (по ARIA-ролям — устойчиво к обфускации классов Google).
- Поддерживает 3 типа вопросов: **один вариант** (radio), **несколько вариантов**
  (checkbox), **свободный текст** (short answer / paragraph).
- Два режима (настраивается): **подсказка** (подсветить/показать ответ) или
  **автозаполнение** (вписать ответ в форму).
- **Никогда не нажимает «Отправить»** — финальную проверку и отправку делает
  пользователь.
- **Два источника ответов** (переключаются в настройках):
  - **Gemini** — облако, нужен бесплатный API-ключ.
  - **Локальная модель на устройстве** — без ключа, через `flutter_gemma`
    (MediaPipe/LiteRT-LM). Модель скачивается один раз. Пресеты (все **без
    токена**): Gemma 4 E2B (2.4 ГБ, по умолчанию), Gemma 4 E4B (4.3 ГБ, для
    мощных телефонов), Qwen2.5 1.5B (1.6 ГБ, лёгкая). Требуется iOS 16+ /
    Android 8+ (arm64), желательно ≥6–8 ГБ ОЗУ.
- Заточен под тесты по **иностранным языкам** (вуз переводчиков/гуманитариев):
  системный промпт играет роль эксперта-филолога/переводчика; есть настройка
  «целевой язык» и свой системный промпт.
- Локальный кэш ответов (sqflite) по хэшу вопроса — не дёргает Gemini дважды.

## Архитектура (кратко)

```
WebView (Google Form)
  ├─ assets/js/parser.js  → парсит вопросы, шлёт в Dart (onQuestions)
  └─ assets/js/apply.js   → подсветка / клик / вписывание ответа
        ▲                         │
        │ evaluateJavascript      │ callHandler
        ▼                         ▼
lib/webview/form_screen.dart  ─ FormController
                                   ├─ AnswerCache (sqflite)
                                   └─ GeminiClient → Gemini REST (на устройстве)
                                        └─ prompts.dart / answer_parser.dart
```

Чистое Dart-ядро (`models/`, `util/question_hash.dart`, `ai/prompts.dart`,
`ai/answer_parser.dart`, `webview/form_controller.dart`) не зависит от Flutter UI
и покрыто юнит-тестами в `test/`.

## ⚠️ Окружение: почини Flutter перед запуском

На текущей машине `flutter` сломан (несовпадение сборок Dart VM и `flutter-tool`,
`Wrong full snapshot version`). Это системная проблема пакетов Arch — нужен root.
Варианты:

```sh
# 1) синхронизировать пакеты к совместимым сборкам
sudo pacman -Syu dart flutter-tool

# 2) или поставить официальный Flutter SDK (со своим dart внутри)
git clone -b stable https://github.com/flutter/flutter ~/flutter
export PATH="$HOME/flutter/bin:$PATH"
```

Проверка: `flutter --version` должен вывести версию без ошибки снапшота.

## Запуск

```sh
cd google_form_app

# 1) сгенерировать нативные папки (android/ios/…) — lib/ и assets/ не затрагиваются
flutter create . --platforms=android,ios

# 2) зависимости
flutter pub get

# 3) тесты ядра
flutter test

# 4) запуск на устройстве/эмуляторе
flutter run
```

После запуска: открой **Настройки** (шестерёнка) → вставь ключ Gemini, выбери
модель и режим → вернись, вставь ссылку на форму (`…/viewform`) → «Открыть».

## Заметки и ограничения

- **Вход в Google в WebView**: формы, требующие авторизации, Google иногда
  блокирует во встроенном WebView. Приложение задаёт обычный Chrome-UA, чтобы
  снизить риск; самые надёжные — формы без обязательного входа.
- **Модель**: по умолчанию `gemini-2.5-flash`; для сложных языковых тестов в
  настройках можно выбрать «pro»-класс. Актуальные id моделей — в документации
  Gemini.
- Ключ Gemini хранится в защищённом хранилище устройства (Keychain/Keystore) и
  отправляется напрямую устройство→Google.
- Селекторы парсера могут потребовать доводки под конкретные формы — логика
  изолирована в `assets/js/parser.js` и `assets/js/apply.js`.
