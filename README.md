# LMS Quiz Automation Tool

Инструмент автоматизации прохождения тестов в Moodle LMS (на примере
[lms.bsuir.by](https://lms.bsuir.by/)). Стажировский проект для EPAM.

## TL;DR

Гибрид Chrome MV3-расширения и локального Python-бэкенда. Расширение работает
в реальной пользовательской сессии браузера (естественный stealth), бэкенд
ходит в AI (Gemini Pro primary, локальная Gemma fallback) и хранит историю
попыток в SQLite. Поддерживает три режима: подсказчик (assist), полный
автомат (full-auto), пошаговое подтверждение (step-by-step).

## Этика и ответственность

Инструмент создан в академических целях для саморазвития и демонстрации
инженерных навыков на стажировке EPAM. Использование на реальных
оцениваемых тестах — на ответственности пользователя и регулируется
правилами учебного заведения.
